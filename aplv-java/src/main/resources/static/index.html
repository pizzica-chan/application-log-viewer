    正規表現サンプル
    
      
    
        ロガー・スレッド・メッセージ・全文検索・ソースファイルの各フィールドは正規表現に対応しています。
        マッチは大文字小文字を区別しません。
      
    
      
    
        
          
    
            パターン
            説明
            マッチ例
          
    
            
        
          
    
            Exception
            文字列を含む（部分一致）
            NullPointerException
          
    
          
    
            error|warn
            いずれかに一致（OR）
            ERROR, WARN
          
    
          
    
            Hoge.*Controller
            任意の文字列を挟む
            HogeUserController
          
    
          
    
            ^NullPointer
            先頭から一致
            NullPointerException: null
          
    
          
    
            timeout$
            末尾まで一致
            connection timeout
          
    
          
    
            org\.example\..*
            ドットをリテラルに（FQCN の prefix）
            org.example.service.UserService
          
    
          
    
            application\.log
            ファイル名の部分一致
            C:\logs\application.log
          
    
          
    
            ajp-nio-8009
            ハイフンを含むスレッド名
            ajp-nio-8009-exec-24
          
    
          
    
            \[ERROR\]
            角括弧をリテラルに（エスケープ）
            [ERROR]
          
    
          
    
            \d{3}\.\d{3}\.\d{3}\.\d{3}
            IPv4 アドレス形式
            192.168.1.10
          
    
          
    
            userId=\d+
            数字の連続
            userId=12345
          
    
          
    
            (?s)Exception.*at com\.example
            複数行にまたがる全文検索（grep 向け）
            スタックトレース全体
